# Goodform Studio

A responsive creative studio site built with React and Vite. Portfolio and editorial visuals use local assets; exploratory project work and studio content are identified as concepts rather than client claims.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

The app includes page views for services, case studies, studio information, process, journal entries, contact, careers and legal pages. Configure the production host to serve `index.html` for these routes.

Before launch, replace `example.com` in `public/robots.txt` and `public/sitemap.xml`, update the placeholder contact email, connect the newsletter form to a mailing-list provider, and replace draft legal copy with reviewed policy text.
